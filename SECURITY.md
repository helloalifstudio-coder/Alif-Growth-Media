# Security and Responsible Disclosure

Alif Growth Media takes the security of project repositories and client information seriously.

## Reporting a concern

If you discover a potential vulnerability involving this agency website or an Alif Growth Media project, please report it **privately** to [hello.alifstudio@gmail.com](mailto:hello.alifstudio@gmail.com) with a concise description, the affected component, and enough detail to reproduce the issue safely.

Do **not** put passwords, API keys, unredacted screenshots, database extracts, personal information, exploit demonstrations against third parties, or sensitive customer documents into public GitHub issues or pull requests.

## Scope

The website and linked projects may have separate maintainers, dependencies, deployment environments and security policies. Specify the repository and environment to which a report applies. A public demonstration with browser-only fictitious data is not a production authentication environment.

## Handling and coordination

We aim to review reports responsibly and coordinate an appropriate fix, but this file is **not** a promise of a particular response time, bounty, security certification or service-level agreement. Please avoid accessing data that is not yours or disrupting services.

## Deploying a client project

Use separate client-owned accounts and least-privilege credentials, keep secrets server-side, and validate authentication and authorization before production handover. Never commit client data, access tokens, private contracts or customer login credentials to source control.
